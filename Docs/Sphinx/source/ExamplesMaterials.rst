Parts, labels and materials
===========================

Which part of an object a point or a ray found, with labels and a table of your own; objects of several
materials with the domains a solver computes in; and the same written as a model file, read at run time.

* :ref:`Chap:ExampleSurfaceLabels`: which part of an object a query found, and a table of your own indexed by
  its label.
* :ref:`Chap:ExampleMaterials`: several materials in one object, as regions, and each region's own function.
* :ref:`Chap:ExampleLanguage`: a model read from text (the .ebg language): its domain built for the tape, and its
  properties as a table a GPU reads.
